# InjectCheck

Test your AI chatbot before your customers do.

InjectCheck is a free, browser-based tool that sends prompt-injection test
attacks to a chatbot you own, checks the replies with deterministic rules,
and shows a report with a score and plain-language fixes in English and Hindi.

**Team:** Zero Trust Squad | **Event:** Build With Bharat 5.0

## Features
- 24 test attacks in 6 categories
- Rule-based evaluation (no AI judge)
- English and Hindi interface and report
- Offline demo simulator (no API key needed)
- Printable report

## Run locally
Open `index.html` in a browser. No install or build step.

## Privacy
Your API key stays only in your browser tab's memory and is never saved.
Prompts are sent only to the AI provider you choose. Use demo prompts, not
confidential ones.

## Limitations
This is a simulation with fixed test attacks. A high score does not
guarantee that a chatbot is safe. Test only chatbots you own or have
permission to test.
