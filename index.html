Frequently Asked Questions

What is prompt injection?

Prompt injection happens when untrusted user input tricks an AI into ignoring its original instructions, leaking private instructions or carrying out unauthorized actions.

Why do you use a canary token?

A canary token is a secret string appended to the prompt. If this secret shows up in the model's reply under attack, it deterministically proves the bot leaked its internal context.

Will my API key be stored or saved?

No. The API key exists only in active browser memory during your tab session. As soon as you refresh or close the tab, the key vanishes completely.

What if I encounter CORS errors when testing my API?

Modern browsers block cross-origin calls if the API server doesn't send CORS headers. Google AI Studio and OpenAI allow direct browser calls. For local or custom models, ensure CORS is enabled or run through a local reverse proxy.

Can this tool guarantee 100% security for my AI chatbot?

No automated tool can guarantee absolute LLM security. InjectCheck audits against the top standard vectors. You should always pair prompt hardening with strict backend permissions, input filtering, and least-privilege API scopes.
